usable functions for openpyxl
- load_workbook(filename = "")  ex;  wb = load_workbook(filename = "files/test teoretisk database+historikk.xlsx) https://openpyxl.readthedocs.io/en/stable/api/openpyxl.reader.excel.html#openpyxl.reader.excel.load_workbook
- check what sheets exists: .sheetnames ex; print(wb.sheetnames)  prints a list of sheetnames
- choose sheet:
    - ws = wb["sheet navn"]  ex: history = wb["historikk"]
- grab value:
    - ws["cell number"].value

- max column and row:
    - ws.max_row  or ws.max_col, returns an int of the max amount of rows used. goes all the way to the end, so even if everything between 1 and 2000 is empty, it will return 2000

- set cell value to None to delete it. 

- wb.save("filename") to save the document. in this case: wb.save("files/filename")

- to get every value in a column i'd need to loop through it.
